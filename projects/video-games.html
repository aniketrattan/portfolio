Study 02 / Machine learning

Video Game

A classification study using more than 7,500 video game records to understand the signals behind platform availability and user scores.

02/2024 — 07/20247,500+ recordsPython
ANALYSIS / 02

The question

What actually predicts performance?

I processed and explored more than 7,500 video game records, using data cleaning, preprocessing, and exploratory analysis to understand which variables carried useful signal.

The models

Compare different ways to classify.

I built and evaluated Random Forest, Logistic Regression, and Decision Tree classifiers on the same analysis workflow, keeping the comparison focused on the resulting performance rather than the model name.

The result

79% accuracy and 0.87 ROC AUC.

The analysis identified platform availability and user scores as key predictors across the records, giving the project a concrete result to evaluate and explain.
